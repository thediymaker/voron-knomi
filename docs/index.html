Firmware for the BTT KNOMI V2

KNOMI-NG

Drawn eyes that react to your printer, print progress with the model's thumbnail, and a screen for the Box Turtle. Made for Voron printers running Klipper.

Install over USB

Works in Chrome and Edge on a desktop. Already running the stock firmware on Wi-Fi? You can install over Wi-Fi instead and keep the stock GIFs.

  1. Plug in the KNOMIUse a USB-C data cable. If the installer can't find it, hold the KNOMI's button while plugging in.
  2. Click InstallPick the KNOMI's serial port when the browser asks.
  3. Set it upJoin the KNOMI-xxxx network shown on its screen and open 192.168.4.1.
Your browser can't talk to USB devices. Use Chrome or Edge on a desktop. The installer needs a secure (https) page.

This replaces everything on the KNOMI, including the stock GIFs. You can go back to the stock firmware at any time.

Screens

Swipe between them on the KNOMI. It returns to the face on its own, or jumps to whatever needs attention.
